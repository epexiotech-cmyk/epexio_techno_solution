# Project Setup & Testing Guide
This guide provides step-by-step instructions to run the **Epexio Techno Solutions** website and its **Admin Panel** locally for testing.
## 1. Prerequisites
Ensure you have the following installed on your machine:
- **Node.js** (v14 or higher recommended)
- **npm** (comes with Node.js)
## 2. Installation
Open your terminal/command prompt in the project root directory and run:
```bash
npm install
```
This will install all necessary dependencies, including `browser-sync` and `npm-run-all`.
## 3. Running the Development Servers
To start both the website and the admin panel simultaneously, run:
```bash
npm run dev
```
This command will start two local servers:
1.  **Website Server:** Runs on [http://localhost:3000](http://localhost:3000)
2.  **Admin Panel Server:** Runs on [http://localhost:3001](http://localhost:3001)
## 4. Accessing the Application
### A. Main Website
Since the website files are located in `src/web_pages`, you can access the home page at:
- **URL:** [http://localhost:3000/src/web_pages/index.html](http://localhost:3000/src/web_pages/index.html)
### B. Admin Panel
The admin panel is accessible at:
- **URL:** [http://localhost:3001](http://localhost:3001)
#### Admin Login Credentials (Local/Mock Mode)
In the current local development environment, the login is mocked. You can use any non-empty credentials to log in:
- **User ID:** `admin` (or any text)
- **Password:** `admin` (or any text)
> [!NOTE]
> The Admin Panel is configured to fetch data from the `data/` directory in the root. If you make changes in the Admin Panel (like deleting a project or updating a status), it will attempt to save via a mock API.
## 5. Troubleshooting
- **Port already in use:** If port 3000 or 3001 is already in use, you can modify the ports in the `package.json` file under the `scripts` section.
- **Missing Images:** Ensure the `Image/` directory exists in the root folder, as the website and admin panel reference assets from there.
